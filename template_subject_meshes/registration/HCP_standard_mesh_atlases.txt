HCP standard mesh atlas deformation spheres and ROIs (for fs_LR <-> fsaverage resampling)
by Washington University / HCP Pipelines (and neuromaps package)

* source: HCP Pipelines global/templates/standard_mesh_atlases
          (also distributed via the Python package 'neuromaps', which bundles these files)
* purpose: correct spherical registration between the fs_LR 32k and fsaverage (164k)
          templates. The fs_LR 32k sphere is NOT in the same spherical coordinate system
          as FreeSurfer's sphere.reg, so naive resampling scrambles the anatomy. These
          'deformed' spheres bring both meshes into the same (fsaverage) space, which is
          what wb_command -label-resample / -metric-resample require.
* license: HCP data usage terms (https://www.humanconnectome.org/study/hcp-young-adult/data-use-terms)
* downloaded at: 2026-08-29
* files:
  - fs_LR-deformed_to-fsaverage.{L,R}.sphere.32k_fs_LR.surf.gii   (fs_LR 32k mesh in fsaverage space)
  - fsaverage_std_sphere.{L,R}.164k_fsavg_{L,R}.surf.gii          (fsaverage standard sphere, 164k)
  - fs_LR.32k.{L,R}.vaavg_midthickness.shape.gii                  (vertex area averages, fs_LR)
  - fsaverage.164k.{L,R}.vaavg_midthickness.shape.gii             (vertex area averages, fsaverage)
  - fs_LR.32k.{L,R}.nomedialwall.label.gii                        (cortex ROI, fs_LR)
  - fsaverage.164k.{L,R}.nomedialwall.label.gii                   (cortex ROI, fsaverage)
